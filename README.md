# Project Title: Word Counter

This is a simple Python command-line tool to count the number of words in a given text file.

## Features
- Counts words in a specified text file.
- Handles basic file errors.

## Usage
To use the tool, run the script from the command line and provide the filename as an argument:
```bash
python word_counter.py <filename>
```
